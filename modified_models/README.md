# Модификация архитектуры Neural Radiance Fields (NeRF)

В данном разделе задокументированы все основные этапы и эксперименты, проведённые с целью улучшения результатов оригинального бэйзлайна (`torch-ngp`) без потери в скорости обучения.

## 1. Контекст и генерация гипотез
Взяв за точку отсчета репозиторий `torch-ngp` (бейзлайн на базе Instant-NGP), был сформирован шорт-лист из перспективных архитектурных подходов, базирующихся на исследованиях 2023–2026 годов и собственных авторских идеях, нацеленных на снижение "алиасинга" и проблем коллизий в Multi-Resolution Hash Encodings. Основной фокус — улучшение качества реконструкции при сопоставимой скорости обучения.

## 2. Изолированная имплементация нескольких экспериментов
Для строгого сравнительного контроля (ablation study) были разработаны и внедрены независимые модификации, каждая в своей папке и наследующая логику оригинального бэйзлайна. Ключевые эксперименты (кратко):

- EXP-01: Spatially-Adaptive Hash Masking — обучаемые пространственные маски. (Δ PSNR: -0.12 @10k)
- EXP-02: Rotated Multi-Resolution Hash Encoding (R-MHE) — повороты координат по уровням. (Δ PSNR: +0.02 @10k)
- EXP-03: Frequency Regularization (G2fR-style). (Δ PSNR: -1.33 @10k)
- EXP-04: Hybrid Positional + Hash Encoding. (Δ PSNR: -0.24 @10k)
- EXP-05: Enhanced MLP Decoder (64→128, residual, GELU). (Δ PSNR: +0.27 @10k)
- EXP-06: Scale-Aware Level Weighting (anti-aliasing heuristic). (Δ PSNR: +0.14 @10k)
- EXP-07: Opacity Regularization + Total Variation Loss. (Δ PSNR: -0.35 @10k)
- EXP-08…EXP-12: Доп. модификации (SCJ, PFM, GMLP, LDS, NOVE и т.п.) — небольшие положительные/отрицательные эффекты в пределах ±0.4 dB на 10k.
- EXP-13_1: Learnable Error Predictor — ухудшение (Δ PSNR: -0.40 @10k).
- EXP-13_2: Boundary-Aware Sampler (приоритизация сэмплирования на границах объектов) — существенное улучшение (Δ PSNR: +1.29 @10k); на 30k стабильный выигрыш и ускорение обучения.

Подробные 10k-результаты занесены в EXPERIMENT_LOG.md.

## 3. Долгое обучение (30k) — финальный бенчмарк
Проведены 10 запусков каждого конфига (Baseline и EXP-13_2) на сцене Lego, по 30,000 итераций для статистической значимости.

Итоговые усреднённые метрики:
- Baseline: PSNR = 33.96, SSIM = 0.9741, LPIPS = 0.0141, Время = 11.7 мин
- EXP-13_2: PSNR = 34.68, SSIM = 0.9771, LPIPS = 0.0115, Время = 10.3 мин

Выводы:
- Победитель — конфигурация EXP-13_2: средний выигрыш +0.72 dB PSNR на 30k итерациях при одновременном сокращении времени обучения ~12%.
- Значимое улучшение LPIPS (0.0141 → 0.0115) отмечено визуально — меньше "зубчатости" на краях и чище тени.
- Работа с сэмплированием лучей (приоритизация границ) оказалась более эффективной, чем большинство архитектурных изменений, при сохранении или улучшении скорости.
